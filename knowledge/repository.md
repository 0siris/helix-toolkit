# Overview

This repository currently contains a Silk.NET-based toolkit workspace centered on `Source/SilkToolkit.slnx`.

The active top-level source areas are:

| Path | Purpose |
|------|---------|
| `Source/SilkCore` | Core rendering/runtime library. |
| `Source/SilkToolkit` | Windows/WPF-facing toolkit layer. |
| `Source/SilkAssimp` | Assimp model loading integration. |
| `Source/SilkToolkit.Native.ShaderBuilder` | Shader build support. |
| `Source/Examples` | Demo and test applications for SilkCore and SilkToolkit. |
| `docs` | Migration and repository structure notes. |

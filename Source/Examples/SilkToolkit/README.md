# SilkToolkit Examples

WPF demo applications for the SilkToolkit renderer, browsable through the
`ExampleBrowser`. Thumbnails are generated by running each demo in Debug mode
(see `ExampleBrowser/ReadMe.txt`).

## Getting started

| Demo | Shows |
| --- | --- |
| `SimpleDemo` | Minimal scene setup |
| `ExampleBrowser` | Browser hosting every demo |
| `TemplateDemo` | Template for new demos |
| `Viewport3DXCodeBehindTester` | Code-behind viewport usage |

## Rendering techniques

| Demo | Shows |
| --- | --- |
| `DeferredShadingDemo` | Deferred shading path |
| `SSAODemo` | Screen-space ambient occlusion |
| `OrderIndependantTransparentRendering` | Weighted OIT + depth peeling |
| `ShadowMapDemo` | Shadow mapping |
| `PostEffectsDemo` | Post-effect chain |
| `TessellationDemo` | GPU tessellation |
| `VolumeRendering` | Volume ray casting |
| `EnvironmentMapDemo` | Environment lighting |
| `CustomShaderDemo` | Custom shaders and techniques |
| `RenderTechniqueImportExport` | Technique serialization |
